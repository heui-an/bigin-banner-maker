# 빅인 배너 생성기

동아사이언스 빅인 프로모션 배너(720 × 960)를 브라우저에서 만들고 PNG로 내려받는
단일 HTML 도구. 피그마 `빅인 템플릿`을 캔버스에 그대로 옮겼다.

원래 피그마 플러그인이었는데, 템플릿이 쓰는 Gmarket Sans Bold가 설치되지 않은
맥에서 `loadFontAsync`가 조용히 실패하고 `node.characters` 대입이 예외를 던지면서
프레임만 복제되고 내용이 하나도 안 들어가는 문제가 반복됐다. 웹으로 옮기면서
폰트를 함께 두어 이 문제를 없앴다.

## 쓰는 법

`index.html`을 브라우저로 열면 끝이다. 빌드도, 서버도, 의존성도 없다.

- 타이틀 · 상품명 · 가격을 입력하면 즉시 다시 그려진다
- 이미지는 클릭 · 드래그 · `Cmd+V` 붙여넣기 모두 된다 (500 × 500에 꽉 채워 들어감)
- 테마 9종. 스와치 안의 점이 그 테마의 배지 색이다 (배경과 짝이 안 맞는 조합이 많아 표시해 둔다)
- 1× / 2× / 3× 배율로 PNG 저장. 파일명은 `빅인_260922_red.png` 형식

## 템플릿 원본

피그마 파일 `b7aI0Z8tJrEae3zsmRycWI`, `빅인 템플릿` 섹션 노드 `854:4182`.
아래 값은 눈대중이 아니라 그 파일에서 읽어온 실측값이다.

| 요소 | 값 |
|---|---|
| 배너 | 720 × 960 |
| cont | 640 × 832, 세로 중앙, gap 24 |
| 타이틀 | Gmarket Sans Bold 52 / 자간 −2.08 / 행간 68 |
| 상품명 | Pretendard Bold 48 / 자간 −1.92 / 행간 52 |
| 이미지 | 500 × 500, 라운드 24 |
| 가격칩 | 높이 72, 라운드 full, 패딩 32·16 / 16·32, Gmarket Sans Bold 40 / −1.6 |
| 리본 배지 | x 64 y 264 w 90, 패딩 32·16, 글자당 44 (길이 자동), 꼬리 90 × 32 |
| 원형 배지 | 160 × 160 — 상단 x 56 y 224, 하단 x 504 y 564 |
| 배지 글자 | Gmarket Sans Bold 44 / 자간 −1.76 |

테마 색은 피그마에서 변수가 아니라 프레임마다 하드코딩돼 있어 9개를 개별로 읽었다.
`index.html`의 `THEMES` 객체가 그 표다.

## 구조

```
index.html   전부 여기에 있다 (스타일 · 마크업 · 캔버스 렌더러)
fonts/       동봉 폰트 — FONTS.md 참고
```

캔버스에 직접 그리기 때문에 720 × 960이 픽셀 단위로 정확하고, 배율만 바꿔 그대로
확대 저장할 수 있다. 외부 라이브러리는 쓰지 않는다.

## 관련
