# 마케팅 제작도구

동아사이언스 마케팅 이미지를 브라우저에서 만들고 PNG로 내려받는 단일 HTML 도구.
좌측 사이드 메뉴로 도구를 고른다. 빌드도, 서버도, 의존성도 없다.

**https://heui-an.github.io/bigin-banner-maker/**

| 도구 | 크기 | 피그마 원본 |
|---|---|---|
| 빅인 배너 | 720 × 960 | `b7aI0Z8tJrEae3zsmRycWI` / `빅인 템플릿` (`854:4182`) |
| DS스토어 썸네일 | 1000 × 1000 | `WVnhal54s6I2dmWSgXo0Bk` / `썸네일 제작도구 템플릿` (`7756:2412`) |

아래 수치는 눈대중이 아니라 그 파일들에서 읽어온 실측값이다.

## 쓰는 법

`index.html`을 브라우저로 열면 끝이다. 이미지는 클릭 · 드래그 · `Cmd+V` 모두 된다.

## 빅인 배너

| 요소 | 값 |
|---|---|
| cont | 640 × 832, 세로 중앙, gap 24 |
| 타이틀 | Gmarket Sans Bold 52 / 자간 −2.08 / 행간 68 |
| 상품명 | Pretendard Bold 48 / 자간 −1.92 / 행간 52 |
| 이미지 | 500 × 500, 라운드 24, 비율 유지(안 잘림) |
| 가격칩 | 높이 72, 라운드 full, 패딩 32·16 / 16·32, Gmarket Sans Bold 40 / −1.6 |
| 리본 배지 | x 64 y 264 w 90, 패딩 32·16, 글자당 44(길이 자동), 꼬리 90 × 32 |
| 원형 배지 | 160 × 160 — 상단 x 56 y 224, 하단 x 504 y 564 |

테마 9종. 색은 피그마에서 변수가 아니라 프레임마다 하드코딩돼 있어 개별로 읽었다
(`THEMES` 객체). 배경과 배지 색이 짝이 안 맞는 조합이 많아 스와치 안에 배지 색을
점으로 같이 표시한다.

## DS스토어 썸네일

| 요소 | 값 |
|---|---|
| 이미지 | 900 × 900 at (50, 20), 맞춤/채움 선택 |
| 원형 배지 | 지름 240, 중심 (840, 840), 그림자 0 8 8 rgba(0,0,0,.25) |
| 별 배지 | `assets/badge-star.svg` 272 × 272 at (704, 712) |
| 메달 배지 | `assets/medal-frame.svg` 232 at (740, 720) + 리본 2개 ±25° |
| 배지 글자 | Gmarket Sans Bold, 자간 −0.05em, 행간 1.15 |

배지 문구는 배지 안쪽 폭(원형 202 / 별 186 / 메달 156)에 맞춰 글자 크기가 자동으로
줄어든다.

**그라데이션**은 별도 모양이 아니라 시안의 광택 오버레이
(`linear-gradient(141.6deg, …)` + `plus-lighter`)다. 토글로 켜고 끈다.

**색상**은 원형과 별만 바꾼다. 별 SVG는 같은 path 두 개 — 베이스 `fill="#4800FF"` 와
광택 `fill="url(#paint0_linear_0_4)"` — 로 되어 있어서, 베이스 fill만 치환해 색을
바꾸고 광택 path를 제거해 그라데이션을 끈다. 메달은 금색 그라데이션이 모양 자체에
포함돼 있어 색상 변경 대상에서 뺐다.

> 별 색상 변경은 SVG 텍스트를 `fetch` 해서 치환한다. `file://` 로 직접 열면 `fetch`가
> 막혀 원본 보라색으로 폴백한다. 공유할 때는 위 Pages 링크를 쓸 것.

## 구조

```
index.html   전부 여기에 있다 (스타일 · 마크업 · 두 도구의 캔버스 렌더러)
fonts/       동봉 폰트 — FONTS.md 참고
assets/      썸네일 배지 도형 (피그마에서 내보낸 SVG 원본)
```

캔버스에 직접 그리기 때문에 크기가 픽셀 단위로 정확하고, 배율만 바꿔 그대로 확대
저장할 수 있다. 외부 라이브러리는 쓰지 않는다.
